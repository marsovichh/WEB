1. Название и организация
Реальная или учебная, но конкретная (не «некая фирма»).

Название системы: «Учёт заявок на неисправное уличное освещение»
Организация / подразделение: МУП «Горсвет» — диспетчерская служба (учебная организация на базе реального профиля городской эксплуатационной службы)
№ из таблицы примеров (если брали): «Не горит фонарь»
2. Главная сущность и справочник
Главный объект (одна запись процесса): заявка на неисправность светильника (lampRequest)
Справочник (вторая таблица, ссылка числом): участок сети / район эксплуатации (district)
Поле-ссылка (как назовёте в JSON/БД): districtId (число, внешний ключ на district.id)
3. Роли и права
| Роль                    | Создаёт | Назначает | Меняет статус |
| ----------------------- | ------- | --------- | ------------- |
| Диспетчер               | да      | да        | нет           |
| Инженер (электромонтер) | нет     | нет       | да            |
| Руководитель службы     | нет     | нет       | да            |
Исполнитель не назначает себя, если этого нет отдельным требованием.

4. Сценарий в одно предложение
Кто создаёт → кого назначают → кто меняет статус:

Диспетчер создаёт заявку «не горит фонарь» → назначает её конкретному инженеру-электромонтёру на участке → инженер берёт в работу и закрывает её после ремонта (статус меняет инженер или руководитель).

7. Запас под ВКР
Не меньше четырёх пунктов с разных полок (данные/процесс · связи с другими системами · масштаб). В семестре не делают.

Данные: история отказов по каждой опоре, накопление статистики по типам светильников

Процесс: автоматическое распределение заявок по участкам и загрузке бригад

Связи с другими системами: обмен с диспетчерской ГИС, выгрузка в ГИС ЖКХ

Масштаб: многогородняя конфигурация, роли на уровне филиалов, SLA и отчётность

Другая организация (городская служба «Горсвет»), другой главный объект (заявка на светильник с привязкой к участку сети), другие роли (диспетчер / инженер-электромонтёр / руководитель службы) — не совпадает с типовыми «заявками на ремонт» или «заявками на ИТ-поддержку» ни по объекту, ни по справочнику.
